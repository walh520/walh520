## 精选项目

### [RenderingEngine](https://github.com/walh520/RenderingEngine)

把光传输、遍历后端、GPU 执行架构与时域重建放在同一运行时中比较，配套可复现捕获与分层验证。

### [TA GPU Agents](https://github.com/walh520/TA_GPUAgents-Portfolio)

以 Profile 组织鱼群、鸟群与花瓣等 GPU 效果，连接 RDG 调度与 Niagara；新增 Snowfall 核心源码摘录。

### [TARibbon Dynamics](https://github.com/walh520/TARibbon-Portfolio)

围绕 GPU 持久状态、XPBD、Bake 数据与编辑器预览构建单片布料链路，并连接深度、速度和阴影通道。

### [TA Cloud, Fog & Interaction](https://github.com/walh520/TA_CloudFogInteraction-Portfolio)

连接云密度烘焙、周期光线步进与艺术 DA 连续响应，保留雾气交互的数学与数据接口。

### [GeoPointViewer-Vulkan](https://github.com/walh520/GeoPointViewer-Vulkan)

东方杯项目中的二维点云模块，结合屏幕空间 LOD、GPU 页缓存、可见性裁剪与间接绘制，支持选择和剖面分析。
